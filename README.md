# Gatework Studio

A browser-based generator for romantic wrought-iron borders and embellishments. Create variations, adjust weight and taper, and export SVG or PNG artwork.

## Open it

Download this repository using **Code → Download ZIP**, unzip it, and double-click **index.html**. No installation or account is needed to run the generator. Google Fonts loads the interface typefaces when online; fallback fonts work offline.

Settings and design numbering are saved in each person's browser. They are not shared between coworkers. Download the artwork to share a specific result.

If Copy SVG is unavailable when opening the file directly, use Download SVG instead.

## Local preview

Optionally, serve this folder with `python3 -m http.server 8765` and open http://localhost:8765.

## Editing

The application is contained in `index.html`, including its styles, SVG geometry generator, controls, and exports. There is no build step.
